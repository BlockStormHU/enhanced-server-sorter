# 📁 Enhanced Server Sorter

**Folders and a custom order for your servers in the Pelican panel.**

Enhanced Server Sorter brings order to long server lists in [Pelican Panel](https://pelican.dev). Every user can
group their servers into folders and arrange them however they like, and the server list and the server switcher
both follow that order. Administrators can hand out ready-made folders to everyone, and lock the ones that should
stay the same for all users.

## ✨ At a glance

- 📁 Personal folders for every user, in their own order
- 🗂️ A server list grouped into collapsible folders
- 🔀 A server switcher that follows the same order
- 🛠️ Default folders that every user gets automatically, optionally locked
- 🌍 Available in 32 languages
